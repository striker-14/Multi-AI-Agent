First you have to tell what type of agent you want, you want a financial agent, study agent, medical agent. Then you have to type your question, what question you want to ask.

groq will be used as your LLM to generate output for the question that we are asking

Tavily if you want to fetch answer from the internet because on the internet we will get latest results because LLMs are trained on data up to a date in the past

FastAPI to build backend APIs for handling user requests

Deploying our application on AWS

Containerization using Docker

For creating the UI, Streamlit

For interacting with our LLM, we will be using LangChain

For creating our AI Agent, we will be using LangGraph. LangGraph is built on LangChain to create AI Agents and their workflows

LangChain is generative AI framework, LangGraph is Agentic AI framework

SonarQube main use is checking code quality (Bugs, Code Smells, Code Duplication), to check our code for bugs, security issues, and bad practices. It's like evaluator of our app

Jenkins for making CI/CD pipeline

AWS ECS Fargate to deploy and run our app on the cloud

GitHub will be our SCM. Copy the code from GitHub to Jenkins, in Jenkins we will create Docker Image using Docker file that we created and then we will push Docker Image to AWS ECR (container registry where we can store images). From ECR we will deploy it to AWS ECS Fargate. All this whole thing will be connected using Jenkins using a CI/CD pipeline, so if we click on the build now button all these things will get executed
